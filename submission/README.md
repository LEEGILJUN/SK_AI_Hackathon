# 본선 제출 폴더

2026 SK AI 해커톤 AI Solution 리그 본선 제출물입니다. 마감은 **2026-09-03(목)
23:59**, 제출처는 운영측이 팀에 배정한 Google Drive 폴더입니다.

이 폴더는 그 드라이브 폴더와 **같은 구조로 미리 만들어 두는 자리**입니다.
여기서 작업하고 그대로 올립니다.

## 1. 폴더 이름을 바꾸지 않습니다

제출 안내에 이렇게 적혀 있습니다.

> 이름을 바꾸거나 지우거나 새로 만들지 마세요. 평가는 이 구조를 그대로
> 읽어가는 방식이라, 이름이 다르면 그 항목은 비어 있는 것으로 처리됩니다.

```
[팀번호]_[팀명]/
├── 0_본선_안내문/     운영측이 넣습니다. 우리가 만들지 않습니다
├── 1_기획서/
├── 2_결과물/
├── 3_검증결과/
└── 4_제작과정/
```

정리하려고 이름을 손대면 그 폴더는 인식되지 않습니다.

## 2. 폴더마다 심사가 묻는 것

| 폴더 | 심사가 확인하는 질문 | 배점에서 걸리는 자리 |
|---|---|---|
| 1_기획서 | 어떤 문제를 풀려고 했나 | SUPEX 추구 30점 |
| 2_결과물 | 기획서에서 정의한 핵심 기능이 실제로 작동하는가 | 구현 완성도 35점 |
| 3_검증결과 | 작동한다는 걸 어떻게 확인했나 | 재현 가능성 10점 |
| 4_제작과정 | 계획대로 진행했고, 막힌 지점을 어떻게 풀었나 | 집요함과 패기 15점 |

심사위원은 **제출된 자료만으로 판단합니다.** 문서에 없는 내용은 반영되지
않습니다.

## 3. 아직 안 채워진 것

| 무엇 | 누가 | 언제까지 |
|---|---|---|
| 팀번호와 팀명 | 팀 대표 | 드라이브 폴더를 받으면 |
| 작동하는 앱 URL과 접속 계정 | 4090 담당 | 공개 절차는 [`docs/앱주소_공개절차.md`](../docs/앱주소_공개절차.md) |
| 12라인 구성으로 재측정한 값 | 4090 담당 | 뱅크를 다시 세운 뒤 |
| WBS와 회의록 | 팀 전원 | 각자 기록에서 |

**앱 URL이 가장 크게 비어 있습니다.** 열리지 않으면 구현 완성도 35점 중
기능적 완성도 25점을 확인할 수 없다고 규정에 적혀 있습니다.

## 4. 올리기 전에 확인할 것

```bash
python scripts/check_public.py   # 사내 정보·자격증명이 없는가
python scripts/check_docs.py     # 문서 숫자가 코드와 어긋나지 않는가
python -m pytest tests/ -q       # 시험이 통과하는가
```

그리고 **회사망 밖에서 앱 URL을 한 번 더 열어 봅니다.** 같은 노트북의
브라우저에서 열리는 것은 확인이 아닙니다.
