# 심사위원이 누를 주소 만들기 — 4090 공개 절차

본선 규정에 이렇게 적혀 있습니다.

> 작동하는 앱 URL이 열리지 않으면 구현 완성도를 확인할 수 없습니다.

구현 완성도 35점 중 기능적 완성도 25점이 여기에 걸려 있습니다. **지금
우리에게는 열리는 주소가 없습니다.** 이 문서가 그것을 만드는 절차입니다.

**팀 결정 2026-08-21: 4090 을 터널로 공개하고, 배포판에도 모델을 붙입니다.**

---

## 1. 무엇을 세우는가

    심사위원 브라우저
        ↓  https (터널이 만든 고정 주소)
    터널 클라이언트 (4090 노트북에서 실행)
        ↓  http://127.0.0.1:8000
    uvicorn app.main:app
        ↓
    PatchCore 추론 (4090 GPU) · Claude API (도구 순서 판단 · 판별 1·5번)

**바깥에서 4090 으로 들어오는 구멍을 여는 것이 아닙니다.** 터널
클라이언트가 안에서 밖으로 연결을 걸고 그 위로 요청이 돌아옵니다.
공유기 포트를 열 필요가 없습니다.

---

## 2. 주소가 재시작해도 같아야 합니다

**여기서 한 번 크게 틀릴 수 있습니다.** 무료 터널은 대개 실행할 때마다
주소가 바뀝니다. 9월 3일에 제출한 주소를 심사위원이 그 뒤에 누르는데,
그 사이에 노트북이 한 번 재시작하면 **제출한 주소가 죽습니다.**

고정 주소를 주는 것으로 고르세요. 두 가지가 있습니다.

| 방법 | 고정 주소 | 필요한 것 |
|---|---|---|
| **ngrok** | 무료 계정에 고정 도메인 1개 | 가입 · authtoken |
| **Cloudflare Tunnel** | 이름 있는 터널 | Cloudflare 계정 + 보유 도메인 |

도메인이 없으면 ngrok 쪽이 빠릅니다. **어느 쪽을 쓰든 제출 전에 노트북을
한 번 재부팅하고 같은 주소가 열리는지 확인하세요.**

---

## 3. 로그인을 겁니다 — 규정이 허용합니다

> 로그인이 필요하다면 접속 방법도 함께 남겨주시기 바랍니다. (FAQ Q19)

**걸어야 하는 이유가 둘입니다.**

1. **API 키가 붙은 앱입니다.** 주소를 아는 누구나 누르면 우리 계정에서
   토큰이 나갑니다. 심사 기간 내내 열려 있는 주소입니다.
2. **GPU 가 달린 노트북입니다.** 추론이 도는 자리를 아무나 두드리게 두면
   시연 중에 느려집니다.

아이디와 비밀번호를 만들어 **`2_결과물/README` 에 그대로 적습니다.** 숨기면
심사위원이 못 들어옵니다. 이 계정은 이 앱 전용이고 다른 곳에 쓰지 않습니다.

---

## 4. 올리는 데이터 — 규정 확인

보안 가이드 4번이 이렇게 말합니다.

> 배포한 URL은 인터넷에 열립니다. 배포용 앱에는 가상 데이터만 넣으세요.

우리는 이미 맞습니다. **VisA 공개 데이터셋(CC BY 4.0)과 직접 만든 가상
공장 데이터뿐**이고 사내 데이터는 처음부터 없습니다. `scripts/check_public.py`
가 저장소에 자격증명·사내 정보가 없는지 봅니다. 공개 전에 한 번 돌리세요.

---

## 5. 모델을 API 로 붙입니다

**로컬 gguf 로도 돌지만 API 를 권합니다.** 심사위원이 여러 명 동시에
누르면 4090 한 대에 얹힌 12GB 모델이 순서대로 밀립니다. 추론(PatchCore)은
GPU 가, 판단(도구 순서·판별 1·5번)은 API 가 맡으면 겹치지 않습니다.

```
setx SHVO_LLM_PROVIDER anthropic
setx SHVO_VLM_PROVIDER anthropic
setx ANTHROPIC_API_KEY <키>
```

**키를 파일에 적지 마세요.** 환경 변수로만 둡니다. 제출 폴더에도 넣지
않습니다 — 보안 가이드가 명시적으로 금지합니다.

값을 바꾸고 싶으면 이렇습니다.

| 환경 변수 | 기본값 | 무엇 |
|---|---|---|
| `SHVO_LLM_MODEL` | `claude-opus-5` | 안 주면 이것으로 섭니다 |
| `SHVO_LLM_EFFORT` | `medium` | 사고 깊이. 올리면 판단이 좋아지고 느려집니다 |
| `SHVO_LLM_MAX_TOKENS` | 4096 | **사고 토큰이 여기 함께 듭니다.** 낮추면 잘립니다 |

붙었는지는 이렇게 봅니다.

```bash
python scripts/check_models.py
```

응답·JSON·도구 호출·이미지 판독을 각각 한 번씩 실제로 시켜 봅니다.
**여기서 걸리는 편이 시연 중에 멈추는 것보다 낫습니다.**

## 6. 켜 두는 문제

심사는 9월 3일 마감 뒤 9월 9일까지 이어집니다. **그동안 노트북이 켜져
있어야 합니다.**

    절전·최대 절전 끄기        제어판 전원 옵션 (덮개를 닫아도 안 자게)
    자동 로그인               재부팅 뒤 사람 없이 서비스가 뜨게
    uvicorn 자동 재시작        죽으면 다시 뜨게
    터널 자동 재시작           같이

**이 기계는 블루스크린이 세 번 났습니다.** 세 번 다 화면 캡처 자동화
중이었고(`docs/4090_답_크래시와시연멈춤.md`), 우리 스크립트로는 안 났습니다.
심사 기간에는 그 기계에서 캡처 자동화를 돌리지 마세요.

죽어도 다시 뜨게 하는 것이 답입니다. 작업 스케줄러에 "시작할 때" 로
둘을 등록하고, 실패 시 재시작을 켭니다.

## 7. 제출 전 확인 — 다른 환경에서 한 번 더

> 제출 전 다른 환경에서 한 번 더 열어봐 주세요. (본선 평가 기준)

**같은 노트북의 브라우저에서 열리는 것은 확인이 아닙니다.** 회사망 밖,
다른 기계, 되도록 휴대전화 데이터로 한 번 여세요. 사내망 안에서만 열리는
주소를 제출하면 심사위원 화면에서는 안 열립니다.

    □ 휴대전화 데이터로 주소가 열린다
    □ 적어 둔 아이디·비밀번호로 들어가진다
    □ 이슈를 넣으면 열 단계가 끝까지 돈다
    □ 화면에 "언어 모델이 도구 순서를 정했습니다" 가 뜬다
    □ 노트북을 재부팅한 뒤에도 같은 주소가 열린다

마지막 줄이 제일 자주 빠집니다.

## 8. 그래도 노트북이 꺼질 때를 대비하려면

**주소가 하나뿐이면 그 하나가 죽을 때 25점이 통째로 날아갑니다.**
API 키가 있으므로 클라우드에도 같은 앱을 띄울 수 있습니다. GPU 가 없어
추론은 느리지만 판단은 같은 모델이 합니다. 예비 주소를 함께 적어 두면
심사위원이 둘 중 하나로는 들어옵니다.

지금은 안 하기로 했습니다. 필요해지면 이 문서에 절차를 붙입니다.
