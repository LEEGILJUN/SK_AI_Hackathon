## 1. 역추적 좌표로 시각 언어 모델 판독이 되는가 ★ 최우선

**지금 기획서에 들어갈 주장의 전제입니다.** 이게 안 되면 발견 4가
"정답 마스크가 있을 때만 된다"가 되고, 실전에서는 쓸 수 없는 결과가 됩니다.

지난번 실험은 **VisA 정답 마스크로 결함 위치를 짚어** 잘라냈습니다.
실제 운영에는 마스크가 없습니다. **PatchCore 의 이상 점수가 가장 높은
패치로 짚어도 같은 결과가 나오는지**를 재야 합니다.

### 어떻게

`inspection/crop.py` 에 필요한 것이 이미 있습니다.

```python
from inspection import PatchEmbedder, build_bank, score_image, crop_patch
from inspection.crop import crop_with_context
from agents.vision import judge_defect_visible
from agents.adapters import build_adapters

# 1) 뱅크를 만들고 결함 이미지를 추론한다
result = score_image(defect_image, bank, embedder, root=root, top_k=1)

# 2) 이상 점수가 가장 높은 패치의 좌표 — 정답 마스크를 쓰지 않는다
top = result.matches[0].query          # PatchRef(row, col)

# 3) 그 자리를 원본에서 잘라낸다
patch = crop_patch(defect_image, top, (result.grid_h, result.grid_w),
                   embedder.config, margin=24, enlarge_to=512)
context = crop_with_context(defect_image, top, (result.grid_h, result.grid_w),
                            embedder.config, context_cells=3)

# 4) 시각 언어 모델에 묻는다
_, vlm = build_adapters()
judgment = judge_defect_visible(vlm, patch, reported_defect="표면 결함")
```

### 무엇을 재나

VisA capsules 결함 10장 이상으로:

| 재는 것 | 왜 |
|---|---|
| **역추적 좌표가 실제 결함 위치와 겹치는가** | 마스크와 대조. 이게 먼저다 |
| 그 크롭으로 VLM 이 결함을 맞히는가 | 지난번 마스크 크롭(6/6)과 비교 |
| 정답 마스크로 자른 것과 차이가 얼마나 나는가 | 두 방식을 나란히 |

`inspection/crop.py` 의 `patch_box()` 가 좌표를 픽셀 영역으로 돌려주므로,
그 영역과 마스크의 겹침(IoU 또는 중심 포함 여부)을 직접 계산할 수 있습니다.

### 결과에 따라

- **겹치고 VLM 도 맞히면** → 기획서에 조건 없이 쓸 수 있습니다. 발견 4가 완성됩니다
- **좌표는 맞는데 VLM 이 틀리면** → 크롭 크기·여유·확대 배율을 바꿔 봅니다
- **좌표가 안 맞으면** → 이게 제일 중요한 발견입니다. 미검출 상황에서는
  히트맵도 못 믿는다는 뜻이고, 판별 1번 설계를 다시 봐야 합니다

어느 쪽이든 기획서에 쓸 내용이 나옵니다.

## 2. 언어 모델 도구 호출이 되는가

웹 데모를 도구 호출 경로로 바꾸는 작업(Mac 담당)의 **전제**입니다.
도구 호출이 안 되는 모델이면 그 작업을 해도 소용이 없습니다.

```bash
set SHVO_LLM_PROVIDER=openai_compat
set SHVO_LLM_BASE_URL=http://localhost:11434/v1
set SHVO_LLM_MODEL=qwen3-14b
set SHVO_VLM_PROVIDER=openai_compat
set SHVO_VLM_BASE_URL=http://localhost:11434/v1
set SHVO_VLM_MODEL=qwen3vl-8b

python scripts/check_models.py
```

네 가지를 각각 실제로 시켜 봅니다 — 응답 / JSON 출력 / **도구 호출** /
이미지 판독. **도구 호출 항목이 통과하는지가 핵심**입니다.

VRAM 16GB 에 `qwen3-14b`(8.4GB) + `qwen3vl-8b`(5.8GB) = 14.2GB 이므로
둘 다 상주 가능하다고 브리핑에 적혀 있습니다. 실제로 동시에 물릴 때
문제가 없는지도 함께 봐 주세요.

**안 되면 모델을 바꿔야 합니다.** 그게 결과입니다.
