### 1. 네 작업을 맥으로 넘겨줘

커밋 안 한 파일 7개(12라인·정상 1,000장·오염 13장·품목별 임계값·보충 경로)를
올려야 해. **`git add -A` 는 쓰지 마.** 세션 셋이 같은 워크트리를 쓰고 있어서
남이 작업 중인 파일이 딸려 들어가.

```bash
git status                      # 무엇이 바뀌었는지 눈으로 확인
git add <바꾼 파일만>
git commit -m "12라인 · 정상 1,000장 · 오염 13장"
git rebase origin/main
```

**충돌이 나면 네 것을 남겨.** 라인 구성·뱅크 장수·오염 장수·임계값·보충
경로 다섯 자리는 네 방향이 이기기로 정했어. 다만 `docs/4090_병합지침.md`
3장의 넷은 살려줘. 특히 `_stale_composition` 은 **정상 1,000장으로 바꿔도
어제 세운 뱅크가 그대로 실리는 것**을 막는 자리라, 없으면 새 구성이라
말하고 옛 뱅크로 돌게 돼.

푸시는 막혀 있으니 번들로 보내줘.

```bash
git bundle create 4090.bundle origin/main..main
git bundle verify 4090.bundle
```

**돌려줄 것: `4090.bundle` 파일 하나.** 정상이면 수백 KB 야. 뱅크나 VisA 가
들어가면 안 돼.

### 2. 결정 둘을 알려줘

**(가) 품목별 임계값을 어디에 둘까.**
너는 `PER_OBJECT_THRESHOLD` 상수로, 맥은 `lookup.get_threshold(라인, 품목,
뱅크)` 로 받게 해 뒀어. **값은 네 실측이 맞아.** 자리만 정하면 돼. 조회
계층에 두면 데이터 담당 실구현이 붙을 때 그대로 갈아끼워지고, 상수로 두면
그 자리가 코드에 박혀. 맥 쪽은 `MockLookup(thresholds={(라인,품목): 값})`
로 이미 배선돼 있어서 네 표를 그대로 넣기만 하면 돼.

**(나) 12품목 중 어디를 커버리지 부족 라인으로 둘까.**
야간 로트를 뱅크에서 빼는 라인이야. 고르는 근거는 둘이야.

1. 그 품목에서 **미검이 실제로 생기는가.** 뱅크가 조건을 모르면 정상 점수가
   올라가 과검이 늘고, 현장은 임계값을 올려 둬. 그 임계값에서 결함이 묻히는
   것이 이 라인의 미검이야. 미검이 0장이면 3단계에서 멈춰 — 네가 겪은 그
   자리야.
2. `data/issue_history.jsonl` 에 **같은 라인·품목·결함유형이 해결됨으로
   있으면 접수가 중복으로 끊어.** 그 조합은 피해야 해.

**돌려줄 것: (가) 어느 쪽인지, (나) 어느 품목인지와 그 근거.**

### 3. VisA 에서 라인별 시연이 실제로 도는지

12라인으로 합친 뒤에 확인해줘. **합성으로는 확인이 안 되는 것들이야.**

```bash
python -m pytest tests/ -q
python scripts/run_demo.py                        # 기본 라인
python scripts/run_demo.py --item <오염 라인>
python scripts/run_demo.py --item <커버리지 라인>
python scripts/run_demo.py --item <깨끗한 라인>
```

`--item` 은 이제 접수 제품명까지 그 라인 것으로 바꿔. `--threshold` 기본값도
비웠어. 값을 적으면 그것이 이기고, 안 적으면 품목별 값을 써. **전에는 2.20 이
박혀 있어서 품목별 임계값이 영영 안 쓰였어.**

**돌려줄 것: 라인마다 이 다섯 줄.**

```
라인 · 품목
재검사에서 미검 몇 장 / 과검 몇 장
진단이 낸 원인
계획이 뱅크를 건드렸는가
완주했는가, 못 했으면 몇 단계에서 왜
```

**미검이 0장이면 그 자리를 적어줘.** 그게 제일 자주 막히는 곳이야.

### 4. 심사위원이 누를 주소 열기 — 배점에서 가장 큰 자리

본선 규정에 **"작동하는 앱 URL이 열리지 않으면 구현 완성도를 확인할 수
없습니다"** 라고 적혀 있어. 35점 중 25점이 여기 걸려 있고 지금 우리에겐
열리는 주소가 없어. 절차는 `docs/앱주소_공개절차.md` 에 있어.

**(가) 재시작해도 같은 주소가 나오는 터널을 골라줘.** 무료 터널은 대개 실행
할 때마다 주소가 바뀌는데, 9월 3일에 제출한 주소를 심사위원이 그 뒤에 눌러.
그 사이 재부팅 한 번이면 죽어. ngrok 무료 계정에 고정 도메인 1개가 붙어.

**(나) 모델을 API 로 붙여줘.**

```
setx SHVO_LLM_PROVIDER anthropic
setx SHVO_VLM_PROVIDER anthropic
setx ANTHROPIC_API_KEY <키>          # 키는 환경 변수로만. 파일에 적지 마
```

```bash
python scripts/check_models.py
```

응답·JSON·도구 호출·이미지 판독을 각각 실제로 한 번씩 시켜 봐. **여기서
걸리는 편이 시연 중에 멈추는 것보다 나아.**

**돌려줄 것**
```
check_models.py 출력 전체
터널 주소 (열리면)
로그인을 걸었다면 아이디·비밀번호
회사망 밖(휴대전화 데이터)에서 열리는지 확인했는지
재부팅 뒤에도 같은 주소인지 확인했는지
```

**계정이 아직 없으면 무엇이 필요한지만 알려줘.** 사람이 만들어야 하는
것이면 거기서 멈추고 알려줘.
