# 시연 영상 각본

2026 SK AI 해커톤 예선 선택 제출물. 총 길이 약 2분 20초.

**올린 영상: https://youtu.be/NdkgI8rJRqg**

초안은 화면 담당 세션이 냈고, 숫자와 확정은 이 문서에서 합니다.
**모든 수치는 최신 화면에서 그대로 옮긴 것입니다.**

---

## 1. 이 각본이 지키는 것

**화면에 없는 말을 자막이 하지 않습니다.** 자막은 화면에 이미 있는 것을
가리키기만 합니다. 자막이 앞서 나가면 "화면은 저런데 말은 다르네"가 됩니다.

**숫자를 계산하지 않습니다.** 아래 값은 전부 화면 집계를 옮긴 것입니다.
재실행해서 값이 달라지면 자막도 함께 고칩니다.

**줄바꿈 대시를 쓰지 않고 문장은 짧게 끊습니다.**

---

## 2. 녹화 전 확인

| 확인할 것 | 기대값 |
|---|---|
| `git rev-parse HEAD` | `efc2fd2` 이상 |
| 화면 상단 표시 | **언어 모델이 도구 순서를 정했습니다** |
| 진행 레일 | 열 단계 전부 완료 |
| 히트맵 | 64×64 격자가 상자 안에 들어감 |

**해시를 눈으로 대조하고 시작합니다.** 시연 장비는 `fetch` 가 조용히
실패한 전력이 있고, 옛 코드로 찍으면 히트맵이 상자를 넘쳐 아래 글자를
덮은 채로 녹화됩니다.

**`driver` 표시가 특히 중요합니다.** 모델이 안 붙은 화면이면 "순서를 모델이
정한 것이 아닙니다"가 떠 있는데, 그 위에 장면 2의 자막을 얹으면 화면과
자막이 정반대가 됩니다. 그때는 장면 2의 대체 문안을 씁니다.

---

## 3. 장면 순서

| | 장면 | 화면 | 길이 |
|---|---|---|---|
| 1 | 문제 제기 | 이슈 접수 | 15초 |
| 2 | 열 단계 진행 | 진행 레일과 도구 호출 기록 | 20초 |
| 3 | 원인 추적 | 진단 근거: 히트맵과 역추적 두 자리 | 30초 |
| 4 | 같은 화면, 반대 조치 | 판별 5번을 바꿔 재실행 | 25초 |
| 5 | 신구 비교 | 신구 비교 재생 (가상 라인) | 25초 |
| 6 | 승인 요청에서 멈춤 | 승인 요청과 문서 | 25초 |

### 장면 4를 빼지 않습니다

`CLAUDE.md` 가 못박은 것입니다.

> 뱅크 오염과 정상 분포 중첩은 **반드시 함께 구현하고 시연합니다.**
> 둘의 구분이 진단의 핵심입니다.

> 진단 성능의 시험대는 재학습을 해야 할 때 하는가가 아니라,
> **하지 말아야 할 때 멈추는가**입니다.

장면 4가 없으면 영상이 "문제를 고치는 자동화"로만 읽힙니다. 넣으면
**고치지 않기로 판단하는 것도 결과**라는 것이 보이고, 5단계에서 멈춘 진행
레일이 그것을 그림으로 증명합니다.

**시간이 모자라면 15초로 줄이되 빼지 않습니다.**

## 4. 자막 문안

한 장면당 2~4줄, 한 줄 25자 안팎입니다.

### 장면 1. 이슈 접수

```
현장에서 올라온 이슈는 이미지가 아니라 제품명과 로트입니다.

자연어 한 줄이면 됩니다.
라인과 품목은 언어 모델이 여기서 뽑습니다.

정보가 모자라면 추측하지 않고 되묻습니다.
```

**가리키는 곳**: 입력 칸과 그 아래 안내 문구.

라인·품목 칸이 비어 있는 것이 설계입니다. 미리 채워 두면 언어 모델이 뽑을
일이 없어집니다. 자막이 그것을 설명할 필요는 없지만, 심사위원이 "왜 비어
있나"로 읽지 않게 첫 줄이 먼저 나가야 합니다.

### 장면 2. 열 단계 진행

```
접수부터 승인 요청까지 열 단계입니다.

각 단계는 도구 하나이고,
어떤 순서로 부를지는 언어 모델이 정합니다.

순서를 어기면 도구가 거부합니다.
```

**가리키는 곳**: 진행 레일, 그리고 도구 호출 기록 표.

화면에 `gemma4-12b-vision 가 도구 10개를 순서대로 불렀습니다` 가 적혀
있습니다. 자막은 그것을 가리키기만 합니다.

**고정 순서 화면이면** 세 번째 줄을 이렇게 바꿉니다.

```
이 영상은 고정 순서로 실행한 것이고,
화면이 그렇다고 표시합니다.
```

### 장면 3. 원인 추적

```
못 잡은 이미지가 뱅크의 어느 정상 패치와 가까웠는지
되짚을 수 있습니다.

판단 근거가 모델 안에 이미 있습니다.

왼쪽이 못 잡은 자리, 오른쪽이 뱅크의 그 자리입니다.

결함이면 뱅크 오염 하나로 정해집니다.
진짜 정상품이면 셋으로 나뉘고,
판별 6번과 임계값 스윕이 그것을 가릅니다.
```

**가리키는 곳**: 히트맵, 역추적한 두 크롭, 그 아래 설명 문단.

**화면 문장이 한때 "진짜 정상품이면 정상 분포 중첩"이었고, 그것이 틀린
것이었습니다.** `decide()` 는 진짜 정상품이면 커버리지 부족·임계값 문제·
정상 분포 중첩 셋으로 가릅니다. `1c5b67c` 에서 화면을 고쳤고 자막은 그
문장을 따릅니다.

**"진짜 정상품이면 재구성이 답이 아니다"로 묶어도 틀립니다.** 셋 중
커버리지 부족은 재구성이 필요합니다. **조치가 정반대인 것은 뱅크 오염과
정상 분포 중첩 두 짝뿐**입니다.

### 장면 4. 같은 화면, 반대 조치

```
판별 5번 하나만 바꿔 다시 실행합니다.

같은 이미지, 같은 점수, 같은 최근접 패치입니다.

원인이 뱅크 오염에서 임계값 문제로 갈리고,
뱅크 재구성이 금지 조치가 됩니다.

여섯 원인 중 넷은 다시 만드는 것이 답이 아닙니다.

진행 레일이 5단계에서 멈춥니다.
고장이 아니라 결론입니다.
```

**가리키는 곳**: 시연 조정 칸, 진단 카드의 금지 조치(`rebuild_bank`),
진행 레일의 회색 칸, 멈춘 자리 카드.

**화면이 "시연을 위해 지정한 값"이라고 스스로 적으므로 조작이 아닙니다.**
그 표시를 가리지 마세요.

### 원인이 정상 분포 중첩이 아닙니다

처음에는 이 장면을 「뱅크 오염 대 정상 분포 중첩」으로 잡았는데, **실제
화면은 임계값 문제로 나옵니다.** 규칙이 틀린 것이 아니라 맞게 동작한
것입니다.

`decide()` 는 판별 5번이 진짜 정상품이면 임계값 스윕을 보고 가릅니다.
스윕이 "해결 가능"이면 임계값 문제, "해결 불가"면 정상 분포 중첩입니다.
그런데 **pcb1 은 깨끗한 뱅크든 오염된 뱅크든 스윕이 해결 가능으로
나옵니다**(과검 0%로 전건 검출). 그래서 이 뱅크와 이 이미지로는 정상
분포 중첩이 원리적으로 나오지 않습니다.

**자막에 "정상 분포 중첩"이라고 적으면 화면과 어긋납니다.** 심사위원이
화면을 보면 바로 보입니다.

**보여주려던 것은 그대로 성립합니다.** 여섯 원인 중 넷은 재구성이 답이
아니고, 그 넷 중 하나가 화면에서 재구성을 실제로 거부합니다. **하지
말아야 할 때 멈춘다**가 증명됩니다.

정상 분포 중첩을 실제로 보이려면 스윕이 "해결 불가"인 뱅크가 필요합니다.
실측에서 capsules 가 그랬는데, 그 품목은 시연에도 시나리오에도 없어
공장 품목으로 끼우는 작업이 필요합니다. **예선 마감 전에는 하지
않습니다.**

### 장면 5. 신구 비교

```
새 뱅크를 실제 판정에 쓰지 않습니다.

같은 이미지에 두 뱅크를 나란히 돌려
판정이 서로 다른 것만 뽑습니다.

14장 중 1장만 사람이 확인하면 됩니다.
```

**가리키는 곳**: 신구 비교 재생 벨트와 아래 집계.

**14장 중 1장**은 화면 집계 그대로입니다(새로 검출 1, 새로 놓침 0).
재실행해서 달라지면 자막도 고칩니다.

### 장면 6. 승인 요청에서 멈춤

```
배포 패키지와 승인 요청 문서까지 만듭니다.

배포는 실행되지 않습니다.

배포 승인: 아니오. 사람이 결정합니다.

품질 검사 설비라 의도적으로 뺀 경계입니다.
```

**가리키는 곳**: 승인 요청 카드의 표와 승인 문서 전문.

**이 장면이 가장 중요합니다.** 무인 배포를 안 한다는 것이 문장이 아니라
화면으로 증명되는 자리입니다. 표에 `배포 승인: 아니오 (사람이 결정)` 과
`승인 후 전환 명령` 이 실제 폴더 이름으로 찍혀 있으므로, 자막은 그것을
가리키기만 하면 됩니다.

**마지막 줄에서 화면을 3초쯤 정지시킵니다.**

## 5. 쓰면 안 되는 말

| 쓰지 말 것 | 왜 | 대신 |
|---|---|---|
| 전부 RAG로 찾습니다 | 사실이 아닙니다. 대부분 조인입니다 | 대부분 조인이고 그래프는 이력 하나입니다 |
| 정확도가 올랐습니다 | 신구 비교에는 정답이 없습니다 | 판정이 서로 다른 건만 확인합니다 |
| 임계값을 바꿔도 원인은 같습니다 | VisA 실측에 반증됐습니다 | (말하지 않습니다) |
| 자동으로 배포합니다 | 배포 기능이 없습니다 | 승인 요청까지 만듭니다 |
| AI가 원인을 판단합니다 | 원인은 규칙이 냅니다 | 판별 7항목으로 규명합니다 |
| 줄바꿈 대시 | 사람이 안 씁니다 | 쉼표, 콜론, 문장 나누기 |

**실명을 넣지 않습니다.** 역할명으로 씁니다.

**실측 초를 자막에 넣지 않습니다.** 재측정하면 오류 없이 낡습니다.

## 6. 촬영과 편집

**편집하지 않습니다.** 한 번 돌린 것을 그대로 쓰는 편이 진짜로 보입니다.
자막으로 지금 무엇이 일어나는지만 표시합니다.

장면 4는 두 번째 실행이라 이어 붙여야 합니다. 그때 **첫 실행과 같은
이슈, 같은 이미지**여야 "같은 화면, 반대 조치"가 성립합니다.

캡처 화면에 창 제목과 경로, 사용자명이 함께 찍히지 않게 **브라우저
콘텐츠 영역만** 잡습니다.
