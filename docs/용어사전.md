# 용어 사전

문서와 코드 주석에 쓰인 말을 모았습니다. 두 종류가 섞여 있어서 나눴습니다.

1. **과제 고유 용어** — 이 과제에서만 특정한 뜻으로 쓰는 말. 정의가 필요합니다
2. **일반 용어** — 업계에서 쓰는 말. 뜻만 확인하면 됩니다
3. **안 쓰기로 한 말** — 이길준이 쓰던 비유. 업계 표현으로 바꿉니다

3번이 왜 있는지부터 적습니다. **이길준이 문서·주석에 비유를 많이 썼고
그것이 이해를 막았습니다.** "그물", "못 박다", "두 벌", "자리표시" 같은
말은 AI 업계에서 안 쓰는 표현입니다. 처음에 몇 개였던 것이 아무도 지적하지
않는 사이 늘었습니다. 아래 표의 오른쪽으로 씁니다.

---

## 1. 과제 고유 용어

### 뱅크 (memory bank)

**PatchCore 가 정상 패치 벡터를 모아 둔 것.** 정상 이미지를 격자로 잘라
각 칸의 특징 벡터를 저장해 두고, 검사할 때 **가장 가까운 정상 패치와의
거리**로 이상 여부를 판정합니다.

이 과제의 출발점이 여기 있습니다. 거리로 판정하므로 **미검출이 나면 "그
이미지가 뱅크의 어느 정상 패치와 가까웠는지" 되짚을 수 있습니다.** 판단
근거가 모델 안에 이미 있다는 뜻이고, 진단이 추측이 아니라 추적이 됩니다.

`inspection/bank.py` · 벡터는 `bank.npz`, 구성 이력은 `bank_meta.json`.

### 뱅크 재구성 (rebuild)

뱅크를 다시 만드는 것. 이미지를 빼거나 더한 뒤 다시 벡터를 뽑습니다.
**미검출 원인 6종 중 넷은 재구성이 답이 아닙니다.** 그래서 "재구성해야
할 때 하는가"보다 **"하지 말아야 할 때 멈추는가"** 가 시험대입니다.

### 미검 (미검출) · 과검 (과검출)

- **미검** — 불량인데 양품으로 판정. 이 과제가 다루는 문제
- **과검** — 양품인데 불량으로 판정. 임계값을 내리면 늘어납니다

둘은 맞바꿈 관계라 한쪽만 보면 안 됩니다. 임계값을 낮춰 미검을 줄이면
과검이 늘고, 현장에서는 그것도 비용입니다.

### 판별 항목 7가지

미검출 원인을 가리기 위해 재는 것 일곱. `agents/diagnose.py`.

| # | 무엇을 보는가 | 어떻게 |
|---|---|---|
| 1 | 결함이 이미지에 실제로 보이는가 | 시각 언어 모델 |
| 2 | 화질 지표가 기준을 벗어났는가 | 통계 비교 |
| 3 | 이상 점수가 임계값 대비 어디인가 | 추론 결과 |
| 4 | 가장 가까운 정상 패치가 무엇인가 | 뱅크 역추적 |
| 5 | 그 패치가 결함인가 진짜 정상품인가 | 시각 언어 모델 또는 사람 |
| 6 | 현재 조건의 정상 패치가 뱅크에 있는가 | 뱅크 구성 이력 |
| 7 | 판정 기준상 불량이 맞는가 | 기준 테이블 |

**4번과 5번이 함께 작동하는 지점이 핵심입니다.** 가장 가까운 패치를 찾는
것만으로는 부족하고, 그것이 잘못 들어간 결함인지 진짜 정상품인지를 구분해야
원인이 갈립니다 — 결함이면 뱅크 오염, 정상품이면 정상 분포 중첩이고
**조치가 정반대**입니다.

### 원인 6종

| 원인 | 뜻 | 재구성이 답인가 |
|---|---|---|
| 임계값 문제 | 점수는 높은데 임계값 아래 | 아니오 |
| 뱅크 오염 | 정상 세트에 결함이 섞임 | **예** |
| 커버리지 부족 | 그 조건의 정상 패치가 없음 | **예** |
| 정상 분포 중첩 | 결함이 정상과 형상이 비슷함 | 아니오 |
| 설비·광학 | 화질이 기준을 벗어남 | 아니오 |
| 기준 문제 | 검출은 했는데 기준상 양품 | 아니오 |

### 역추적 (traceback)

미검출 이미지의 각 패치가 **뱅크의 몇 번째 행과 가장 가까웠는지** 되돌아
찾는 것. 그 행이 어느 원본 이미지의 어느 격자 칸에서 왔는지까지 나옵니다.
`MemoryBank.origin_of()`.

### 오염 (contamination)

**결함의 종류 이름이 아닙니다.** 정상 이미지만 들어가야 할 메모리 뱅크에
결함 이미지가 섞여 들어간 **상태**를 말합니다.

    뱅크 = 정상 이미지의 패치 모음
           새 이미지가 이 모음에서 얼마나 먼가로 판정한다

    오염 = 그 "정상 모음"에 결함이 섞임
           결함이 뱅크 안에 있으니 비슷한 결함이 와도 "가깝다" = 정상 판정
           → 미검출

현장에서는 "이 로트 다 정상이야" 하고 넣었는데 그중 몇 장이 실제로 불량이었던
경우입니다. 시나리오에서는 정상 폴더에 결함 이미지 2~5장을 일부러 넣어
만듭니다.

**처음 쓸 때는 풀어 쓰세요.** 이 단어만 반복하면 결함 이름으로 읽힙니다 —
실제로 그런 오해가 있었습니다.

**오염이 있다고 오염으로 진단하지 않습니다.** 오염이 실제로 이상 점수를
끌어내렸을 때만 반복 지목이 성립합니다. VisA 실측에서 pcb1 은 오염이 점수를
24.4% 끌어내려 미검 12건이 전부 오염원을 지목했고(12/12), capsules 는 점수가
안 떨어져(2.6975 → 2.7030) 한 번도 지목하지 않았습니다(0/12). **뒤쪽이 옳은
동작입니다** — 그 미검의 원인은 오염이 아니었습니다.

**실측에서 오염 이미지 비중 3.2% 일 때 결함 위 패치는 뱅크의 0.1% 였습니다.**
coreset 이 끌어올리는 것은 "결함이 **있는 이미지**"이지 "결함 **그 자체**"가
아닙니다. 그래서 통계로 훑어서는 못 찾고 역추적이 찾습니다.

### 코어셋 (coreset)

뱅크가 너무 커지지 않게 대표 벡터만 골라 남기는 것. **서로 먼 점을 우선**
남기는 greedy 방식이라 O(k·N) 이고, 비율을 크게 잡으면 끝나지 않습니다.
`DEFAULT_MAX_BANK_SIZE = 20,000` 상한이 걸려 있습니다.

### 고립도 (isolation)

뱅크 안에서 유독 동떨어진 이미지를 찾는 지표. 오염원을 찾으려고 만들었는데
**실측에서 후보 1개 중 오염원 0개**였습니다. 오염은 패치 단위로 일어나는데
지표는 이미지 단위라, 오염 이미지가 남긴 404개 중 결함 위는 6개뿐이고
나머지 398개가 값을 희석시킵니다. 지금은 보조 근거로만 씁니다.

### 스윕 (threshold sweep)

임계값을 조금씩 바꿔 가며 검출률·과검률 곡선을 그리는 것.

**한계가 있습니다.** 오염된 뱅크와 정상 분포 중첩에서 **똑같이 "해결 불가"가
나옵니다.** 두 원인은 조치가 정반대인데 스윕은 그 갈림을 못 만듭니다.
그래서 진단이 역추적을 임계값보다 먼저 봅니다.

### 홀드아웃 (holdout)

성능을 재려고 따로 떼어 둔 데이터. 뱅크 구성에 쓰지 않습니다.

**AUROC 는 홀드아웃 구성이 다르면 직접 비교할 수 없습니다.** 같은 조건에서
capsules 가 0.998 과 0.989 로 갈린 적이 있는데, 원 측정이 어느 25장을 썼는지
기록이 없어서였습니다.

### 섀도 (shadow) 평가

**신규 뱅크를 실제 판정에 쓰지 않고, 같은 이미지에 병렬로만 추론시켜 판정이
갈리는 케이스만 뽑는 것.**

양산 데이터에는 정답이 없고, 신규 뱅크를 배포하면 기존 뱅크는 더 이상
동작하지 않아 같은 조건 비교가 불가능합니다. 섀도는 그것을 피합니다. 사람은
불일치 건만 확인하면 되므로 공수가 줄고 정답도 확보됩니다.

**홀드아웃과 다릅니다.** 홀드아웃은 별도 데이터로 성능을 재는 것이고,
섀도는 같은 데이터에 두 모델을 돌려 차이를 보는 것입니다.

### 게이트 (gate)

배포 후보가 통과해야 하는 기준. 검출률·과검률·AUROC·재현성 등.
`agents/gate.py`. **지금 값은 전부 임시값이고 장영진이 정합니다.**

### 인테이크 (intake)

이슈를 접수해 **구조화하고 진행 여부를 판단하는** 첫 단계. 정보가 부족하면
추측하지 않고 되묻고, 이미 해결된 사례면 중복으로 끊습니다.

### 중복 차단

같은 이슈가 또 들어왔을 때 진단하지 않고 끊는 것. 조건 넷이 다 맞아야
합니다 — 같은 라인 · 같은 품목 · 같은 결함유형 · 해결됨.

**다른 라인의 같은 증상은 중복이 아닙니다.** 라인마다 뱅크가 따로이므로
1라인이 오염됐다고 2라인도 그렇다는 뜻이 아닙니다.

### 이슈 이력 그래프

과거 이슈를 개체와 관계로 표현한 것 — 이슈 → 원인 → 조치 → 결과.
`data/issue_history.jsonl`. **역할은 중복 차단 하나입니다.** 과거가 비슷하다고
이번 원인을 그것으로 정하면 진단이 유사도 맞히기가 됩니다.

### 조회 계층 (lookup layer)

공장 데이터에서 값을 가져오는 함수 8개. `lookup/base.py` 가 형식,
`lookup/factory.py` 가 실구현, `lookup/mock.py` 가 임시 대체물입니다.

**조인과 집계로 답하고 벡터화하지 않습니다.** "3라인 A-217 로트 이미지
목록"은 정확히 답할 문제이고, 임베딩하면 비슷한 로트를 섞어 옵니다.

## 2. 일반 용어 — 뜻만 확인

| 말 | 뜻 |
|---|---|
| PatchCore | 정상 패치를 모아 거리로 이상을 찾는 이상탐지 기법 |
| VisA | Amazon Science 의 공개 외관검사 데이터셋 (CC BY 4.0) |
| AUROC | 정상·불량을 얼마나 잘 가르는지. 1.0 이 완벽, 0.5 가 무작위 |
| 임계값 (threshold) | 이 값을 넘으면 불량으로 판정하는 경계 |
| 이상 점수 (anomaly score) | 뱅크와 얼마나 먼가. 높을수록 이상 |
| 히트맵 | 이미지의 어느 칸이 얼마나 이상한지를 색으로 |
| 크롭 (crop) | 이미지 일부를 잘라내는 것 |
| MES | 생산 실행 시스템. 로트·설비·시각 같은 생산 기록 |
| 로트 (lot) | 같은 조건에서 함께 생산된 묶음 |
| 매니페스트 (manifest) | 이미지가 어느 라인·로트·일자에 속하는지 적은 대장 |
| 어댑터 (adapter) | 모델을 갈아끼울 수 있게 감싼 계층 |
| VLM | 시각 언어 모델. 이미지를 보고 답하는 모델 |
| 도구 호출 (tool call) | 언어 모델이 함수를 부르는 것 |
| 목 (mock) | 실물 대신 쓰는 가짜 구현 |
| 계약 테스트 | 구현이 정해진 형식을 지키는지 보는 시험 |
| 회귀 (regression) | 고쳐 놓은 것이 나중에 다시 깨지는 것 |

## 3. 안 쓰기로 한 말

**이길준이 쓰던 비유입니다.** 업계에서 안 쓰는 표현이고 이해를 막았습니다.
앞으로 오른쪽으로 씁니다. 옛 문서에 남아 있는 것은 고칠 때 함께 바꿉니다.

| 쓰던 말 | 앞으로 | 왜 |
|---|---|---|
| 그물 | 안전장치 · 마지막 방어 | 비유. "그물"로는 무엇인지 안 보임 |
| 못 박다 | 고정한다 · 시험으로 검사한다 | 비유 |
| 두 벌 | 중복 정의 · 사본이 둘 | "두 벌"은 옷 세는 말 |
| 자리표시 | 임시값 · 플레이스홀더 | 직역투 |
| 접합부 | 인터페이스 · 연결 지점 | 기계 용어 |
| 되짚다 | 역추적한다 | 역추적이라는 말이 이미 있음 |
| 갈린다 · 가른다 | 구분된다 · 구분한다 | 산문투 |
| 덮는다 | 덮어쓴다 · 가린다 | 뜻이 둘로 읽힘 |
| 고정 순서 재생 | 고정 순서 실행 | "재생"은 녹화를 떠올리게 함 |
| 퇴화한 분포 | 분산이 거의 0 인 분포 | 통계 용어지만 설명이 나음 |
| 눈으로 보게 | 화면에 표시 | 산문투 |
| 조용히 (틀린다 등) | 오류 없이 · 알아채지 못한 채 | 의인화 |

**"예열"은 그대로 씁니다.** 운영에서 쓰는 말이고 뜻이 분명합니다 — 시연
전에 미리 실행해 첫 요청이 느린 것을 피하는 것입니다.

## 왜 이 문서가 생겼나

2026-08-15 에 지적을 받았습니다. *"AI 업계에서 잘 안 쓰는 단어가 너무 많아
이해가 안 간다. 이전에도 많았는데 그냥 넘어가니까 점점 더 이상한 단어를
쓰는 것 같다."*

맞는 지적이고, 실제로 세어 보니 그랬습니다. 문서는 읽히려고 있는 것이므로
**읽는 사람이 모르는 말로 적혀 있으면 그 문서는 없는 것과 같습니다.**

새 용어를 만들기 전에 **업계에 이미 있는 말인지 먼저 확인합니다.**
없으면 여기 1장에 정의를 적고 씁니다.
