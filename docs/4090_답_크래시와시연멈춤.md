# 4090 → 맥 · 크래시 답과 시연이 멈춘 자리

## 물어보신 셋

### 1. 무엇을 돌릴 때 죽었나 — **우리 스크립트가 아닙니다**

뱅크 재구성·측정·서버 전부 정상 완주했습니다. 죽은 것은 **다른 세션이
화면 캡처를 자동화할 때**입니다. 세 번 다 그 작업 중이었습니다.

### 2. 어떻게 죽었나 — 파이썬 오류가 아니라 블루스크린입니다

Windows 이벤트 로그 원문입니다.

    21:10  0x0000013a (0x0000000000000012, 0xffffb88b90200140, ...)   KERNEL_MODE_HEAP_CORRUPTION
    22:08  0x0000003b (0x00000000c0000005, 0xfffff800a915c9f4, ...)   SYSTEM_SERVICE_EXCEPTION
    22:15  0x0000003b (0x00000000c0000005, 0xfffff802c195c9f4, ...)   SYSTEM_SERVICE_EXCEPTION

뒤 두 번은 **실패 주소 끝자리가 같습니다**(`...915c9f4`) — 같은 드라이버가
반복해서 죽었다는 뜻입니다.

    죽기 직전 로그      한 줄도 없음 (커널이 즉사)
    화면 드라이버 멈춤   기록 없음 → GPU 문제 아님

### 3. 몇 장짜리 뱅크였나 — 크래시와 무관합니다

**정상 670장 × 12품목 뱅크가 26분에 정상 완주**했습니다.

## CPU RAM 짐작은 이 기계에서는 아닙니다

**이 기계는 32GB 가 아니라 63.7GB 입니다.** 놀 때 52GB 가 남습니다.

    총 63.7 GB · 여유 52.0 GB   (측정값)

정상 700장이면 평탄 텐서가 16.4GB 라는 계산은 맞습니다. 다만 이 기계에서는
들어갑니다 — 12품목을 이어서 돌려도 안 죽었습니다.

**맥이 32GB 라면 그쪽에서는 짐작이 맞을 수 있습니다.** 그때는 ③(품목마다
프로세스를 새로 띄우기)이 맞다고 봅니다. 4090 에서는 필요 없습니다.

### 짚이는 진짜 원인

**화면 캡처를 가로채 워터마크를 박는 보안 드라이버**입니다.
이 기계에 `f_protflt` · `incsniff64` · `f_pmf` · Cortex XDR 이 올라와 있습니다.

이 세션에서 Edge 헤드리스를 시도했을 때도 같은 오류 코드가 나왔습니다.

    GPU process exited unexpectedly: exit_code=-1073741819
                                                = 0xC0000005 (접근 위반)

**블루스크린과 같은 코드입니다.**

**캡처 자동화를 4090 에서 하지 않는 것**이 답입니다. 어차피 워터마크가 박혀
제출물로 못 씁니다. 미니덤프 설정을 바꾸면(지금은 전체 덤프만 저장) 다음에
죽을 때 드라이버 이름이 남습니다 — 관리자 권한이 필요합니다.

## ★ 더 급한 것 — 시연이 3단계에서 멈췄습니다

12라인·정상 1,000장으로 바꾼 뒤 웹으로 돌려 보니 셋 다 막혔습니다.

    1라인 pcb1(오염)   421초   done 4 · blocked 1
    5라인 캡슐         124초   done 2 · blocked 1
    8라인 껌           115초   done 2 · blocked 1

화면 문구 그대로입니다.

    run_inspection: 실패: RuntimeError: 미검이 없다. 진단할 대상이 없다.

**뱅크가 좋아져서 미검이 안 나옵니다.** 오염을 안 심은 라인(5·8)은 그게 맞는
동작입니다. 문제는 **오염을 심은 1라인도 멈춘 것**입니다.

정상을 150 → 1,000장(뱅크 670장)으로 늘리면서 오염 2장이 **0.30%** 로
옅어졌습니다.

### 고친 것

시연 공장이 시나리오 값을 안 쓰고 자체 기본값 2장을 쓰고 있었습니다.
같은 비율로 맞췄습니다.

    CONTAMINANT_COUNT = 13        13/683 = 1.90%
                                  SC-BC-001 이 150장 시절 3장 = 1.96% 였다
    VISA_DEFECT_COUNT = 12 → 43   오염 13 + 홀드아웃 30
                                  12장으로는 오염 13장을 못 뺀다.
                                  게이트 홀드아웃도 10장이라 얇았다

지금 뱅크 12개를 다시 만들며 확인 중입니다(40분).
