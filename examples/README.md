# 예시 모음

각자 담당 파일을 채우기 전에 **형식이 맞는지 확인하는 용도**입니다.

여기 있는 것은 전부 예시이며, 소유 파일이 아닙니다. 그대로 쓰셔도 되고
형식만 참고하고 내용은 새로 짜셔도 됩니다. 다만 **필드 이름과 구조는 맞춰
주세요.** 코드가 그 이름으로 읽습니다.

| 예시 | 대상 | 채울 실제 파일 | 소유 |
|---|---|---|---|
| [`scenarios_예시.yaml`](scenarios_예시.yaml) | 시나리오와 정답 | `data/scenarios.yaml` | 장영진 |
| [`가상공장_구조.md`](가상공장_구조.md) | 폴더트리·MES·조회 | `data/build_factory.py`, `data/manifest.csv`, `data/mes.csv` | 이동현 |
| [`MES_설계.md`](MES_설계.md) | **MES 에 무엇을 더 넣을 것인가** | `data/mes.csv` | 이동현·장영진 |

## 왜 형식을 맞춰야 하는가

진단 에이전트는 이미 돌아갑니다. 다만 지금은 조회 계층이 목(`lookup/mock.py`)
이라 지어낸 값을 봅니다. 실제 데이터가 같은 형식으로 오면 **목을 빼고 실구현을
끼우는 것만으로 끝납니다.** 형식이 어긋나면 그 접합부를 다시 짜야 합니다.

접합부는 두 곳입니다.

- **`lookup/base.py`** — 조회 함수 5개의 시그니처. 이동현 담당
- **`data/scenarios.yaml`의 `ground_truth`** — 채점이 읽는 필드. 장영진 담당

## 지금 상태

```
이슈 접수 → 인테이크 → 판별 7항목 → 원인 6종 판정 → (배포 준비)
   있음      있음        4개 있음      있음           없음
                        3개 목
```

목으로 대체된 3개가 여러분 담당입니다. 판별 5번(시각 언어 모델)은 모델
선정이 남았습니다.

확인은 이렇게 합니다.

```bash
.venv/bin/python scripts/demo_diagnose.py
```
